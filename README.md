# Optima Integrator — wydania

Instalatory Optima Integratora (REST API + MCP dla Comarch ERP Optima).

Do działania programu wymagany jest plik licencji `licencja.lic` wystawiany
indywidualnie — instalator bez licencji nie uruchomi API. W sprawie licencji
skontaktuj się z dostawcą.

Instalacja: pobierz najnowszy `OptimaIntegrator-setup-*.exe`, uruchom, a po
instalacji umieść `licencja.lic` w folderze programu (domyślnie C:\OptimaIntegrator).
Aktualizacja: uruchom nowszy instalator — konfiguracja i licencja zostają zachowane.
